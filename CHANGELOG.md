# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024-01-15

### Added
- Initial release of VideoCall App
- Authentication system with email/password validation
- Video calling functionality with Amazon Chime SDK integration
- User management with REST API integration and offline caching
- Screen sharing capabilities
- Responsive UI with Material Design 3
- State management with Riverpod
- Comprehensive error handling
- App lifecycle management
- CI/CD pipeline with GitHub Actions
- Comprehensive documentation

### Features
- **Authentication**: Secure login with validation and demo credentials
- **Video Calls**: One-to-one video calling with mute/unmute and video toggle
- **User List**: Browse users with offline caching support
- **Screen Sharing**: Share screen during video calls
- **Permissions**: Graceful camera and microphone permission handling
- **Offline Support**: Cached data for offline functionality
- **Responsive Design**: Adaptive UI for different screen sizes
- **Error Handling**: Comprehensive error handling and user feedback

### Technical
- Flutter 3.16.0+
- Riverpod state management
- Amazon Chime SDK integration
- REST API with Dio and Retrofit
- Local storage with Hive
- Navigation with GoRouter
- Material Design 3 theming
- Comprehensive testing setup
- CI/CD with GitHub Actions

### Documentation
- Comprehensive README with setup instructions
- API documentation
- Architecture documentation
- Deployment guides for Android and iOS
