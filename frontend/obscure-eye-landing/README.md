# Obscure Eye Landing Page

This is a modern, cyberpunk-themed React landing page for the Obscure Eye AI security system.

## Features
- Hero section with logo, tagline, and call-to-action
- Problem & solution
- Key features with icons
- How it works
- Screenshots/mockups (placeholders)
- Benefits
- Contact form
- Responsive design

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm start
   ```
3. Open [http://localhost:3000](http://localhost:3000) to view the site.

## Customization
- Replace placeholder text and images in `src/sections/` with your own content.
- Add your screenshots to `public/screenshots/` and update the code.
- Edit theme colors in `src/theme.js` if needed.

## Deployment
- Deploy to Vercel, Netlify, or your own server for public access.
